# 주장 강도와 근거 수준 점검

> 점검일: 2026-07-26. 강한 주장은 강한 표현보다 반박당하지 않는 사실관계에서 나온다. 아래 등급은 주장을 약화하려는 것이 아니라, 기관이 한 문장의 오류를 이유로 전체 요구를 무시하지 못하게 하는 장치다.

## 네 가지 등급

| 등급 | 의미 | 문장 형식 |
|---|---|---|
| 확인 | 공식 원문 또는 복수의 신뢰할 자료로 확인 | `확인된다`, `기재돼 있다` |
| 정황 | 지도·진술·현장상 강한 단서이나 결정문 미확보 | `보인다`, `가능성이 제기된다`, `확인이 필요하다` |
| 회의 | 학부모 회의에서 사용한 명칭·인식·요구 | `회의록상`, `학부모들은 …라고 표현했다` |
| 제안 | 채택되지 않은 대안·협상 요구 | `검토를 요구한다`, `대안으로 제시한다` |

## 핵심 주장 판정표

| 주장 | 현재 등급 | 지금 써도 되는 문장 | 확정에 필요한 자료 |
|---|---|---|---|
| 소화초가 광교지구보다 먼저 현 위치에 있었다 | 확인 | `소화초는 2002년 이전했고 광교지구는 2004년 지정됐다.` | 이전 기사·사업 연표 확보 |
| 수원시가 광교지구 사업에 참여했다 | 확인 | `공식 사업개요상 수원시는 공동 사업시행자다.` | 공식 사업개요 확보 |
| 학교 땅을 수원시가 강제로 잘랐다 | 미확인 | `학교 토지의 도로 편입 여부와 취득방식을 공개하라.` | 폐쇄지적·용지조서·보상·수용재결 |
| 광교중앙로 선형을 수원시가 단독 결정했다 | 미확인 | `공동 시행자별 선형 결정·협의·결재 역할을 공개하라.` | 시행자협의체·설계 결재·관계기관 협의 |
| 옛 청사 차량 출입구는 남측 하나였다 | 정황 | `옛 지도에는 남서측 연결로가 보이나 출입구 개수는 미확인이다.` | 청사 배치도·항공사진·도로연결허가 |
| A17 서측에 새 차량 출입구가 생긴다 | 정황 | `지적편집도상 서측 연결부의 시설용도와 최종 동선을 공개하라.` | 승인배치도·교통영향평가 차량동선도 |
| 포켓도로가 폐지된다 | 회의 | `회의록에서는 기존 공간의 기능 상실을 포켓도로 폐지라고 표현했다.` | 도로대장·공사구역·현황측량·대체계획 |
| 기존 승하차 공간이 전부 사라진다 | 정황 | `기능이 사라지거나 크게 줄어들 우려가 있다.` | 최종 가설계획·도로점용·현장 경계 |
| 공사가 이미 정식 착공됐다 | 정황 | `현장작업은 확인되나 착공신고 수리일은 미확인이다.` | 착공신고·수리통보·공정별 허가 |
| 수원시에 누적 계획책임이 있다 | 논증 가능 | `과거 공동 시행 참여와 현재 안전행정 권한에 따라 누적 영향을 설명·조정할 책임이 있다.` | 위 확인자료와 현행 조례·권한 |
| 세 가지 포켓도로 대안이 계획됐다 | 제안 | `학부모 회의에서 세 대안을 비교 검토하도록 요구했다.` | 기관별 타당성 검토·결정문 |

## 사용을 피할 표현

| 피할 표현 | 이유 | 대체 표현 |
|---|---|---|
| `수원시가 학교 땅을 강탈했다` | 편입·취득방식·결정주체 미확인 | `공동 시행자로서 편입·보상·수용 경위를 공개하고 누적 영향을 조정하라` |
| `학교 땅 ○㎡를 빼앗겼다` | 기사 면적은 반올림 가능, 현재 승계필지 합계 미확인 | `공식 지적자료로 순감소 면적과 용도별 편입면적을 산정하라` |
| `북측/서측 출입구가 확정됐다` | 지적편집도는 승인 차량동선도가 아님 | `서측 연결부의 시설 종류와 최종 승인동선을 공개하라` |
| `포켓도로가 불법으로 폐지됐다` | 공식 명칭·결정·권원 미확인 | `기존 승하차 기능의 변경 근거와 대체공간 검토를 공개하라` |
| `교육환경평가가 없다` | 공개검색 0건은 부존재 증명이 아님 | `평가서 또는 대상 제외 판단서를 공개하라` |
| `이미 착공했으니 모든 절차가 끝났다` | 선행작업과 법률상 착공은 다를 수 있음 | `공정별 신고·허가와 착공신고 수리 여부를 구분해 공개하라` |

## 이번 점검에서 고친 문장

- 언론 제보문, 공동요구서와 학교장 공문의 `승하차 공간이 사라진다`를 `기능이 사라지거나 크게 줄어들 우려`로 조정했다.
- 옛 청사 출입구를 `남측 한 곳`으로 단정하던 문장을 `남서측 연결로는 보이지만 개수·위치는 공식 도면 미확인`으로 바꿨다.
- A17이 옛 청사와 그 이용 주차공간으로 쓰였다는 확인된 사실과, 청사 전체 경계·출입구 개수라는 미확인 사실을 분리했다.
- 현장 기록 문안의 `사라지는 정차공간`을 `변경·축소가 예상되는 정차공간`으로 바꿨다.

## 자료가 확보되면 올리는 방식

근거문서가 도착할 때마다 `문서명`, `문서번호`, `작성기관`, `작성일`, `해당 페이지·도면번호`를 기록한다. 그 뒤 정황 등급을 확인 등급으로 올리고 관련 문안을 한꺼번에 수정한다. 반대로 자료가 기존 기억과 다르면 주장을 유지하지 말고 즉시 낮춘다.
