# 학부모 실행 매뉴얼

법과 행정절차를 처음 접하는 학부모가 광교 A17 공사 대응을 바로 시작할 수 있도록 만든 실무 순서다.

## 먼저 알아둘 세 가지

1. `정보공개청구`는 기관이 가진 도면·평가서·신고서를 받는 절차다.
2. `국민신문고 민원`은 합동점검, 방음벽 선시공, 공사차량 통제 등 실제 조치를 요구하는 절차다.
3. `학교장 공문`은 학교가 교육지원청·수원시·GH·시공사에 공식 입장을 전달하는 절차다.

세 절차는 서로 대체하지 않는다. 같은 날 병행하고 접수번호와 발송일을 한 표에 기록한다.

## 1. 역할부터 나누기

| 역할 | 인원 | 하는 일 |
| --- | ---: | --- |
| 총괄 | 1명 | 문안 확정, 기관 연락, 회의 일정 관리 |
| 접수 담당 | 1~2명 | 정보공개·국민신문고 접수와 접수번호 기록 |
| 학교 연락 | 1명 | 교장·행정실·학교운영위원회와 공문 협의 |
| 현장 기록 | 2명 이상 | 차량 대수, 사진, 영상, 소음 기록 |
| 기록 담당 | 1명 | 통화·회의·기관 답변을 날짜순으로 보관 |

한 사람이 여러 역할을 맡아도 되지만, 모든 자료는 개인 메신저가 아니라 공동 폴더에 보관한다.

## 2. 오늘 30분 안에 할 일

1. 대표 연락처 하나와 공동 이메일을 정한다.
2. 이 저장소의 `정보공개청구 문안`과 `착공 전 공동요구서`를 연다.
3. 정보공개포털에서 수원시, GH, 수원교육지원청을 각각 선택해 청구한다.
4. 국민신문고에서 수원시 대상 민원을 접수하고 공동요구서를 첨부한다.
5. 접수번호, 접수일, 기관, 담당자를 공동표에 기록한다.
6. 학교장 면담을 요청하고 학교 명의 공문 발송을 요청한다.

## 3. 정보공개청구 방법

접수처: https://www.open.go.kr

1. 로그인 또는 본인인증
2. `청구신청` 선택
3. 기관을 하나씩 선택
4. 제목에 `광교 A17블록 공사 관련 소화초 통학·소음 안전자료` 입력
5. 공개방법은 `전자파일`, 수령방법은 `정보통신망` 선택
6. 청구내용에 정보공개청구 문안을 붙여넣기
7. 접수번호 화면을 저장

청구기관:

- 수원특례시
- 경기주택도시공사(GH)
- 경기도수원교육지원청
- 필요 시 경기도교육청

각 기관이 보유한 자료가 다르므로 같은 문안을 기관별로 별도 접수한다. 공개 여부 결정은 원칙적으로 청구일부터 10일 이내이며, 연장 통지가 올 수 있다.

## 4. 국민신문고 민원 방법

접수처: https://www.epeople.go.kr

수원시 온라인 민원은 국민신문고로 일원화되어 있다.

1. `민원신청` 선택 후 본인인증
2. 제목에 `광교 A17 착공 전 소화초 통학·소음 안전 합동점검 요청` 입력
3. 처리기관은 수원특례시를 우선 선택
4. 공동요구서의 요구사항을 본문에 붙여넣기
5. 현장사진, 동선도, 공동요구서를 첨부
6. 다음 네 가지를 명시적으로 질문
   - 합동 현장점검 날짜
   - 담당부서와 담당자
   - 가설방음벽 설치 완료일
   - 등하교 시간 공사차량 제한 여부
7. 접수번호를 저장

첫 문단에는 감정보다 사실을 쓴다. 공사 위치, 학교와의 관계, 착공 예정, 기존 정차공간 상실, 요구하는 회신기한을 적는다.

## 5. 학교에 요청할 것

학교장 또는 행정실에 다음을 요청한다.

- 학교장 명의로 수원시·GH·시공사·교육지원청에 공동 공문 발송
- 교육시설 안전성평가서와 학교장 검토의견 확인
- 가설방음벽 설치 전후 학교·학부모 입회 측정 요구
- 공사장 방향 교실의 공사 전 기준소음 측정 협조
- 수업·시험·학교행사 시간 고소음 공정 제한 요청
- 학교운영위원회 또는 학부모회 결의

학교가 답변을 보류하면 `누가 결정하는지`, `언제 다시 답을 주는지`, `공문 접수 또는 발송번호가 무엇인지`를 확인한다.

## 6. 현장 기록 방법

### 통학차량

- 등교 07:30~08:30, 하교 주요 시간대를 3일 이상 조사
- 10분 단위 차량 수, 최대 동시정차 차량 수, 평균 정차시간 기록
- 학생 보행선과 차량 동선이 겹치는 위치 표시
- 공사장 출입구와 횡단보도 사이 시야 확인

### 소음

- 학교 경계, 운동장, 공사장 방향 교실을 층별로 기록
- 날짜·시각·장소·창문 개폐·수업 여부·날씨를 함께 기록
- 휴대전화 앱은 변화 추세와 시점 기록용으로만 사용
- 법 위반 판단이 필요하면 수원시에 공무원 입회 공식 측정을 요청

### 사진과 개인정보

- 원본파일을 보관하고 촬영일시와 위치를 메모
- 공개 배포본에서는 학생 얼굴과 차량번호를 가린다.
- 위험상황은 전체 장면, 충돌지점, 표지·도로폭 순으로 촬영한다.

## 7. 전화할 때 읽을 문장

> 광교 A17 공사와 관련해 소화초 통학 및 소음 안전 민원을 접수한 학부모입니다. 민원번호는 ___입니다. 담당부서와 담당자 성함, 합동 현장점검 가능일, 특정공사 사전신고 접수 여부, 가설방음벽 설치 완료 예정일을 확인하고 싶습니다. 답변은 기록을 위해 전자문서 또는 민원 답변으로 부탁드립니다.

통화 후에는 날짜, 시각, 기관, 부서, 담당자, 답변, 다시 연락하기로 한 날짜를 적는다.

## 8. 자주 받는 답변과 재질문

| 기관 답변 | 바로 할 재질문 |
| --- | --- |
| 이미 승인됐다 | 승인번호·승인조건·안전 관련 협의의견과 이행확인 자료를 공개해 달라 |
| 법적으로 문제없다 | 검토한 법 조문, 검토문서 제목·작성일·결재번호를 알려 달라 |
| 방음벽을 설치할 예정이다 | 가설/영구 구분, 높이·연장·재료·설치일·삽입손실 시험일을 알려 달라 |
| 공사 중 관리하겠다 | 측정 위치·주기·원시데이터 공개방법·초과 시 중지 기준을 알려 달라 |
| 담당이 아니다 | 보유기관으로 이송하고 이송기관·부서·날짜를 통지해 달라 |
| 자료가 없다 | 부존재 사유와 작성·검토 의무가 없다고 판단한 근거를 밝혀 달라 |

## 9. 7일 안에 답이 흐리면

1. 국민신문고 원민원에 추가질문을 남긴다.
2. 수원시 새빛민원실 원스톱 상담을 예약한다.
3. 학교·학부모·관계기관 합동 현장점검 날짜를 다시 특정해 요구한다.
4. 경기도의원실에 기존 정담회 후속 이행점검을 요청한다.
5. 국민권익위원회 집단고충민원 준비를 시작한다.
6. 공사 강행 정황은 날짜가 보이게 촬영하고 수원시에 현장 확인을 요청한다.
